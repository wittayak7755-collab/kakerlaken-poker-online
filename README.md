# Kakerlaken Poker Online

เกมการ์ดบลัฟ/จับผิด 2–6 คน เล่นผ่านเน็ตได้แบบเรียลไทม์ (Node.js + Socket.io)

เซิร์ฟเวอร์เป็นผู้ตัดสินทุกอย่าง (authoritative) — ไพ่จริงบนมือผู้เล่นคนอื่นจะไม่ถูกส่งไปที่ฝั่ง client เลย จนกว่าจะเฉลยตอนจบรอบ ป้องกันการแอบดู source/network tab แล้วโกง

## รันในเครื่องตัวเอง (ทดสอบ / เล่นใน LAN เดียวกัน)

```bash
npm install
npm start
```

เปิด `http://localhost:3000` แล้วสร้างห้อง ส่งรหัสห้อง 4 ตัวอักษรให้เพื่อนที่อยู่ "วง LAN เดียวกัน" เข้าด้วย IP เครื่อง เช่น `http://192.168.1.23:3000`

## ขึ้นให้เล่นข้ามเน็ตจริง (ฟรี ใช้เวลาไม่กี่นาที)

เลือกอันใดอันหนึ่ง:

### Render.com (แนะนำ ง่ายสุด)
1. สมัคร/ล็อกอิน render.com → New → Web Service
2. เชื่อม GitHub repo ที่ push โค้ดนี้ขึ้นไป (หรืออัปโหลดตรง)
3. Build command: `npm install` / Start command: `npm start`
4. Deploy เสร็จจะได้ลิงก์แบบ `https://your-app.onrender.com` — ส่งลิงก์นี้ให้เพื่อนเล่นได้ทันที

### Railway.app
1. New Project → Deploy from GitHub repo
2. Railway จะ detect Node.js เองและรัน `npm start` ให้อัตโนมัติ
3. เปิด "Generate Domain" ใน settings เพื่อได้ public URL

### Glitch.com
1. New Project → Import from GitHub
2. ใส่ repo นี้ → Glitch auto-install และรันให้ทันที พร้อมลิงก์สาธารณะ

### ทดสอบด่วนแบบไม่ต้อง deploy ถาวร (ngrok)
```bash
npm install
npm start
# เปิดเทอร์มินัลอีกอันหนึ่ง
ngrok http 3000
```
ngrok จะให้ URL ชั่วคราว ส่งให้เพื่อนเล่นได้ทันที (หมดอายุเมื่อปิด ngrok)

## วิธีเล่น (สรุปในเกม)

1. สร้างห้อง → แชร์รหัส 4 ตัวให้เพื่อน (2–6 คน) → หัวห้องกด "เริ่มเกม"
2. แจกไพ่เท่าๆ กันอัตโนมัติ
3. ถึงตาใคร: เลือกไพ่ 1 ใบในมือ → เลือกเป้าหมาย → ประกาศชื่อสัตว์ (จริงหรือโกหกก็ได้) → ส่ง
4. ผู้รับ: ทาย "จริง/โกหก" ทันที หรือแอบดูไพ่แล้วส่งต่อให้คนอื่น (ห้ามส่งกลับคนที่เคยส่งมาในสายเดียวกัน) พร้อมประกาศใหม่ได้ตามใจ
5. ทายผิด → คนทายเก็บไพ่ไปวางหงายหน้า / ทายถูก → คนที่เพิ่งกล่าวอ้างล่าสุดเก็บไพ่ไปวางหงายหน้า
6. ใครมีสัตว์ชนิดเดียวกันหงายหน้าครบ 4 ใบ หรือไพ่หมดมือตอนถึงตาตัวเอง → แพ้ทันที เกมจบ
7. หัวห้องกด "เล่นใหม่" เพื่อแจกไพ่รอบใหม่ในห้องเดิมได้

## โครงสร้างไฟล์

```
server.js          เกมเอนจิน + socket.io event handlers (ฝั่งเซิร์ฟเวอร์ ผู้ตัดสิน)
public/index.html   หน้าเว็บ (lobby / game / end screen)
public/style.css    ธีมสี รองรับ light/dark อัตโนมัติ
public/client.js    ตรรกะฝั่งเบราว์เซอร์ ผูก UI เข้ากับ socket events
```

## จุดที่ยังไม่ทำ (ถ้าต้องการต่อยอด)
- reconnect อัตโนมัติด้วย session token เมื่อ refresh หน้า (ตอนนี้ disconnect แล้วรีเฟรชต้องเข้าห้องใหม่ด้วยชื่อใหม่ โค้ดฝั่งเซิร์ฟเวอร์รองรับโครงไว้แล้วบางส่วนใน `room.players` ที่เก็บ `connected` flag)
- เสียง/อนิเมชันตอนเฉลยไพ่
- ห้องรอผู้เล่นเกิน timeout แล้วเคลียร์อัตโนมัติ (ตอนนี้ห้องจะอยู่จนกว่าทุกคน disconnect)
